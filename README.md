# RAIFLIX MOVIE COLLECTION (MERN Stack & Machine Learning Integration)

Aplikasi web rekomendasi film berbasis MERN Stack (MongoDB, Express.js, React, Node.js) yang terintegrasi dengan Machine Learning Microservice berbasis FastAPI dan TMDB API Service.

---

## Deskripsi Proyek
Proyek ini dibuat sebagai aplikasi katalog film modern yang menyajikan fitur rekomendasi berbasis *Machine Learning*, serta integrasi trailer video langsung dari TMDB (The Movie Database).

---

## Fitur Utama
* **Katalog & Pencarian Film**: Eksplorasi koleksi film berbasis database NoSQL.
* **Rekomendasi Berbasis ML**: Integrasi microservice FastAPI untuk memberikan rekomendasi film yang relevan.
* **Integrasi Trailer Video**: Pencarian metadata otomatis dari TMDB API untuk menampilkan trailer YouTube.
* **Respon Cepat & Responsif**: UI interaktif menggunakan React, Vite, dan Tailwind CSS.

---

## Tech Stack

### Backend
* **Node.js & Express.js**: Server HTTP & REST API Gateway.
* **Mongoose (MongoDB)**: Object Data Modeling (ODM) untuk pengelolaan database.
* **Axios**: HTTP Client untuk komunikasi antar-service (FastAPI & TMDB API).

### ML & Data Processing
* **Python & FastAPI**: Microservice backend untuk engine rekomendasi ML.
* **Pandas & PyMongo**: Pengolahan dataset dan komputasi data film dari MongoDB.

### Frontend
* **React.js & Vite**: Library UI dan bundler frontend yang efisien.
* **Tailwind CSS**: Framework styling berbasis utility-first.
